## Highlights

商品宫格、无边界素材、透明背景和长图切分，项目保存恢复与批量导出。

## Compatibility

- 历史安装包为 Windows x64、自包含 .NET 10、WiX MSI。
- 保留 CutPic.exe、Program Files/CutPic、LocalAppData/CutPic 和既有 UpgradeCode。
