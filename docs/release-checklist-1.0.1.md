## 4. 出错时的最小处置计划

- [ ] 公开前失败：立即停止后续动作，保存返回码、日志、对象身份和已上传清单，报告用户。不得自动删除 Tag、Release 或附件；删除/更正单独请示。
- [ ] 公开后严重问题：停止推广/进一步上传，记录影响版本与精确哈希，备份页面/附件/日志并通知用户，提出暂时撤回下载或更正说明的方案；任何撤回、隐藏、更正或删除仍需独立授权。
- [ ] 不覆盖历史 v1.0.0，也不把新的不同 ProductCode 的 MSI 塞回同一个 1.0.1 附件。需要修复安装包时提出下一更高三段版本和完整升级验收方案，等待另行批准。
- [ ] 用户端回滚不是直接运行旧 MSI：已安装新版会拒绝降级；卸载后重装旧版及数据恢复必须先备份并独立验证，不能宣称无损回滚已通过。
