# CutPic 商品宫格切图

基于 .NET 10 和 WPF 的离线 Windows 桌面工具。自动识别深色背景上的商品卡片，将每个卡片裁出并用采样到的卡片底色补成 1:1 正方形。

界面使用 MaterialDesignInXAML Toolkit 5.3.2 与 Material Design 3 深色主题。

## 当前功能

- 拖放或打开 PNG、JPG、BMP、WebP 图片
- 多图片任务队列，可逐张校正并整批导出
- 自动识别浅色商品卡片及宫格顺序
- 可按行列、边距和间距生成固定宫格
- 移动、缩放、新增、删除切割框
- 实时显示当前选框的正方形成品预览
- 鼠标滚轮缩放画布，支持 15%–500% 及一键复位
- 每张任务图片独立支持撤销/重做（Ctrl+Z / Ctrl+Y）
- 自动保存输出、宫格和缩放配置
- 从识别结果自动推算行列、边距和间距
- 无边界元素识别：按背景色差提取水彩、贴纸和表情素材
- 可调颜色灵敏度、碎片合并距离、最小面积和裁切留白
- 长图纵向切分：按数量平均、按固定高度或自定义每段高度
- 长图切片始终保持原图完整宽度、连续无间距，并按实际宽高导出
- 支持拖动横向分割线调整相邻切片高度
- 可按期望高度在附近空白区域自动选择长图分割位置，降低切断内容的概率
- 保存和打开 `.cutpic` 项目文件，15 秒定时保存并自动恢复上次会话
- 递归导入整个文件夹中的图片，并显示待检查、已确认、异常和已导出状态
- 导出前检查区域越界及长图覆盖连续性
- 文件重名时支持自动追加序号、覆盖或跳过
- 无边界素材可移除与裁切边缘连通的背景，输出带羽化边缘的透明 PNG
- 自动采样卡片底色，补边而不拉伸商品
- 自动清理卡片圆角外残留的深色大背景
- 导出 PNG 或 JPG，可选 512、800、1024 或保持尺寸

## 运行

```powershell
dotnet run
```

## 发布

```powershell
dotnet publish -c Release -r win-x64 --self-contained false
```

## 发布前验证

运行统一构建与回归检查：

```powershell
.\scripts\verify-release.ps1
```

首次构建或依赖版本发生变化时，请先运行一次 `dotnet restore`。

也可以直接运行应用内置测试，并指定报告位置：

```powershell
dotnet .\bin\Release\net10.0-windows\CutPic.dll --self-test .\test-results\self-test-report.txt
```
