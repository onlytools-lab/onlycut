# OnlyCut 智能切图（原 CutPic）

CutPic 是一款面向 Windows 的轻量级离线切图工具，用于把 AI 生成的商品宫格、无明显边界的图标/贴纸素材，以及营销长图快速拆分成独立图片。

应用基于 .NET 10、WPF 和 MaterialDesignInXAML Toolkit 5.3.2 开发。图片识别、裁切和导出全部在本机完成，不会上传用户图片。

## 功能特性

- 商品宫格：从带卡片边界的 2×3、3×3 等商品图中提取单个商品。
- 无边界素材：识别白色或近似纯色背景上的图标、水彩元素、贴纸和表情。
- 长图切分：把海报、详情页或聊天长图连续拆成若干段。
- 批量处理：一次导入多张图片，逐张检查后统一导出。

## 系统要求

- 面向 Windows x64；各 Windows 版本的安装、升级和卸载验收状态见 `docs/windows-validation.md`。
- x64 处理器。
- 普通发布版需要安装 .NET 10 Desktop Runtime。
- 自包含 MSI 已包含 .NET 10 运行时，目标电脑无需另行安装。
- 已实现 Per-Monitor V2 DPI 感知；各缩放比例和混合 DPI 的实机验收需分别执行。

## 界面概览

主窗口分为三个区域：

1. 左侧任务栏：显示导入图片、缩略图、处理状态、切片数和警告数。
2. 中央画布：显示原图、选框或长图分割线，并提供缩放、旋转和翻转操作。
3. 右侧参数栏：选择处理预设、工作模式、识别参数、透明背景和导出参数。

左右侧栏可以折叠，也可以拖动分隔条调整宽度；布局会自动保存。窗口较窄时，低频顶部操作会自动进入“更多”菜单。

## 快速开始

1. 点击“添加图片”，把图片拖入窗口，或按 `Ctrl+V` 粘贴剪贴板图片。
2. 在右侧选择最接近素材的处理预设。
3. 点击“自动识别”，检查画布上的选框或分割线。
4. 必要时拖动、缩放、新增或删除选框，并检查右侧成品预览。
5. 确认当前任务，继续检查下一张图片。
6. 点击“导出全部”，选择输出文件夹。
7. 在导出总览中勾选需要的切片，然后确认导出。

导出前会检查输出目录写权限、磁盘空间、文件重名、命名冲突、选区越界和源文件覆盖风险。

## 商品卡片模式

适合每个商品外部存在浅色卡片、圆角矩形或明显深浅边界的宫格图。

### 推荐步骤

1. 选择“商品卡片”预设。
2. 工作模式选择“智能元素切图”。
3. 自动选择模式选择“有边界卡片”或“自动判断”。
4. 点击“自动识别”。
5. 检查选框顺序，并通过右侧成品预览确认补边效果。

普通商品切片会按照当前输出尺寸导出为 1:1 正方形。原裁切区域不是正方形时，CutPic 会采样卡片底色补齐，不会拉伸商品。

### 固定宫格

当卡片排列规则但自动识别不稳定时，可以设置：

- 行数和列数；
- 横向、纵向边距；
- 横向、纵向间距。

点击“按参数生成选框”即可创建规则宫格。也可以先自动识别，再使用“从识别结果推算”自动估算宫格参数。

## 无边界素材模式

适合白色或近似纯色背景上的天气图标、水彩元素、贴纸、表情等素材。

### 推荐步骤

1. 选择“无边界图标”或“表情包”预设。
2. 自动选择模式选择“无边界元素”。
3. 调整颜色灵敏度、碎片合并距离、最小面积和留白。
4. 点击“自动识别”。
5. 检查被拆散或错误合并的元素，并手动修正选框。

参数含义：

- 颜色灵敏度：数值越高，越容易把与背景接近的浅色内容识别为主体。
- 碎片合并距离：决定相邻小碎片是否合并为同一个素材。
- 最小面积：过滤噪点和过小元素。
- 留白：在识别到的主体外扩展裁切区域。

## 透明背景导出

勾选“移除背景并导出透明 PNG”后，商品模式会强制使用 PNG。算法只移除与裁切边缘连通的背景，以尽量保留主体内部的白色区域。

去背景来源包括：

- 自动判断：根据当前素材和识别模式自动选择背景来源。
- 无边界背景：适合纯色画布上的独立图标和贴纸。
- 卡片背景：适合商品位于浅色卡片内部的图片。

还可以调整去背景强度、容差和边缘羽化。对复杂图片可使用“吸取背景色”在画布上单击背景位置；按 `Esc` 取消取色。

导出总览会提示几乎没有移除背景、透明区域过多或半透明边缘过多等风险。

## 长图切分模式

选择“长图纵向切分”后，每个切片始终保持原图 100% 宽度，切片之间没有空隙，也不会补成正方形。

支持四种方式：

- 按数量平均切分：输入切片数量，各段尽量等高。
- 按固定高度切分：输入每段高度，最后一段使用剩余高度。
- 自定义每段高度：每行输入一个高度，最后一段自动使用剩余高度。
- 按空白区域智能切分：在期望高度附近搜索更适合的空白位置，减少切断文字或主体。

### 手动调整分割线

- 拖动横向分割线：调整相邻两段高度，总高度保持不变。
- 双击图片：在点击位置新增分割线。
- 选择切片后按 `A`：在当前切片中间新增分割线。
- 选中分割线后按 `Delete`：删除分割线并合并相邻切片。

分割线与相邻边界至少保留 20 像素，防止产生无效切片。

## 画布操作

- 鼠标滚轮：以鼠标位置为中心缩放。
- 适应窗口：完整显示当前图片。
- 适应宽度：让图片宽度填满画布。
- 拖动选框：移动裁切区域。
- 拖动选框右下角：调整选框大小。
- 新增/删除选框：使用画布左上角工具或快捷键。
- 旋转和翻转：位于画布左上角的展开式工具组中。
- 撤销/重做：每张任务图片拥有独立的编辑历史。

EXIF 方向会在图片载入时自动处理，手动旋转和翻转也会写入项目文件，但不会修改原图。

## 任务工作流

任务可能处于以下状态：

- 待检查：已导入或参数发生变化，需要人工确认。
- 已确认：用户确认选区和结果无误。
- 异常：图片无法读取、导出失败或存在需要处理的问题。
- 已导出：任务已成功导出。

任务栏支持按状态筛选、定位下一异常、确认所有无警告任务、重试失败任务，以及仅导出已确认任务。

## 处理预设

内置预设包括商品卡片、无边界图标、表情包和长图切分。可以把当前参数保存为自定义预设，并设置为默认预设。

预设文件带独立版本号。旧格式会自动迁移并保留备份；如果文件来自更高版本，当前版本会进入只读保护，不会覆盖它。

## 导出与命名

### 输出格式和尺寸

- PNG：适合透明背景、图标和需要无损保存的图片。
- JPG：适合不需要透明背景的商品图片，可设置默认质量。
- 正方形输出尺寸：512、800、1024 或保持最大边尺寸。
- 长图模式：始终按实际裁切宽高导出。

### 命名规则

可以选择使用原文件名或自定义前缀，并设置后缀、起始编号和编号位数。长图文件名会包含 `part` 标识。

示例：

```text
女装_01_a.png
活动海报_part_003.png
```

重名文件可以自动追加序号、覆盖或跳过。还可以按源图片创建子文件夹，并在导出完成后自动打开输出文件夹。

### 导出总览

导出总览会显示缩略图、预计文件名、尺寸/背景方式和警告。可以全选、全部取消或只选择无警告项。批量导出支持进度显示、取消、单项失败不中断和最终结果汇总。

## 项目、恢复与最近项目

- 项目文件扩展名为 `.cutpic`。
- 项目保存任务列表、选区、长图模式、旋转/翻转、背景取色和任务状态。
- 默认每 15 秒保存恢复会话，可在设置中修改为 5–300 秒。
- 启动时可以自动恢复上次会话。
- “更多 → 最近项目”会列出最近使用且仍然存在的项目文件。
- 配置和项目使用原子保存，并保留 `.bak` 备份，降低写入中断造成的损坏风险。

## 常见问题与故障排查

### 图片导入后显示不完整

先使用“适应窗口”。CutPic 以图片像素作为画布坐标，并自动处理 EXIF 方向和非 96 DPI 图片。如果仍异常，请通过“设置 → 关于 → 导出诊断包”提供日志。

### 没有识别到任何元素

- 商品图尝试“有边界卡片”。
- 白底素材尝试“无边界元素”。
- 提高颜色灵敏度或最小面积过滤条件。
- 降低碎片合并距离，避免多个对象被合并。
- 使用固定宫格或手动新增选框。

### 浅色主体被当作背景移除

降低去背景强度或容差，切换背景来源，或者使用吸管手动指定背景色。复杂毛发、透明玻璃和多色渐变背景并不是当前轻量算法的主要适用场景。

### 文件无法打开或导出

应用会区分文件不存在、权限不足、文件占用、磁盘空间不足、路径过长、文件损坏和格式不兼容，并给出相应建议。建议先关闭占用文件的程序，确认输出目录可写，并把特殊格式转换为标准 RGB PNG/JPG。

### 应用无法启动

查看：

```text
%LocalAppData%\CutPic\crash.log
%LocalAppData%\CutPic\Logs
```

也可以临时备份后移走 `settings.json`，排除旧配置问题。不要直接删除项目和图片文件。

## 当前限制

- 暂未针对超大图片实现分块解码和低内存流式处理。
- 去背景属于轻量边缘连通算法，不是完整抠图或蒙版编辑器。
- 自动识别结果仍可能受复杂背景、元素重叠、阴影和极低对比度影响，需要人工复查。
- 当前正式安装包面向 Windows x64。

## 数据与隐私

CutPic 不需要网络即可完成图片处理。应用日志记录运行事件和错误信息，但诊断包不会主动收集或打包用户图片与项目文件。用户可以在 `%LocalAppData%\CutPic` 中查看或清理本地数据。

## 版本与候选发布治理

`Directory.Build.props` 是产品版本唯一来源：本分支测试版本 `1.0.1` 映射程序集与文件版本 `1.0.1.0`，并传入 WiX ProductVersion。MSI 限制 major/minor ≤255、build ≤65535；不通过第四段区分升级版本。

SDK 由 `global.json` 选择 .NET 10.0.402，并只允许同 feature band 的补丁滚动。候选工作流仅通过 Actions Artifact 保存 MSI、元数据和 SHA-256；不创建 Tag 或 Release。详细流程见 `docs/release-process.md`。
